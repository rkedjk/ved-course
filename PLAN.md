# План: интерактивная обучающая лекция по «Учёт и анализ ВЭД» на GitHub Pages

## Context

Есть лекция `ved-lekciya.md` (конспект рукописной тетради по предмету «Учёт и анализ ВЭД», преподаватель Карпушина Е. В.). Хотим превратить её в обучающую интерактивную SPA-лекцию: аннотации, ссылки на законы, геймификация, мини-игры, приколы. Хостинг — GitHub Pages. Стек — React + TypeScript + Vite + NPM, по максимуму переиспользуя готовые библиотеки.

**Требования пользователя (уточнено):**

- Главное — «живые» примеры: каждое понятие должно быть показано интерактивно, а не сухим текстом и терминами
- UI: Tailwind CSS, стилистика Tinkoff Design System (TDS) — как в соседнем репо `trading` («косим под Т-Банк»)
- Контент: структурированные интерактивные модули (не рендер исходного markdown)
- Деплой: сделать полностью, gh cli доступен (аккаунт `rkedjk`), GitHub Actions как в `trading`

**Образцы:**

- Деплой: `/Users/rad.mustafin/Code/trading/.github/workflows/deploy.yml` — скопировать 1-в-1
- Стилистика TDS: `/Users/rad.mustafin/Code/trading/src/style.css` + `index.html` — токены (жёлтый `#FFDD2D`, `#FAB619`, `#FFF5C2`; светлая `#333/#FFF/#F6F7F8`; тёмная `#202020/#292929`; успех `#00B92D`, ошибка `#F52222`, warning `#FAA805`; радиусы 12/16px; шрифт Manrope; тёмная/светлая тема с переключателем)
- Логика симулятора валютной позиции: `/Users/rad.mustafin/Code/trading/src/main.ts` — порт на React

### Сквозная геймификация

- Квиз после каждого блока (свои компоненты, а не react-quiz-component — кастомнее): варианты, мгновенная проверка, объяснение
- XP + уровни, прогресс-бар как в Duolingo, достижения (badges: «Таможенник», «Спекулянт», «Валютный рисколог»...), конфетти за правильные ответы
- Флэш-карточки для заучивания терминов (глоссарий)
- Приколы: мемы-карточки, шутки в духе Т-Банка («Банк в шорте», «курс вырос — а у банка шорты»), тостеры с юмором, easter eggs
- Прогресс и XP — localStorage (zustand + persist)
- Аннотации: кликабельные термины с тултипами, ссылки на законы (consultant.ru: 183-ФЗ, 164-ФЗ, ТК ЕАЭС), блок «как в конспекте» (исходный текст лекции разворачивается), пометки нечитаемых фрагментов `[??]`

## Approach

SPA на React 19 + TS + Vite, Tailwind CSS v4 (плагин `@tailwindcss/vite`), токены TDS через CSS-переменные, тёмная/светлая тема. Деплой — GitHub Actions на Pages (копия workflow из `trading`), репо создаётся через `gh`.

### Библиотеки (подобраны через web search)

| Пакет | Зачем |
| --- | --- |
| `react`, `react-dom` | основа |
| `vite`, `@vitejs/plugin-react`, `typescript` | сборка (base `'./'`) |
| `tailwindcss` v4 + `@tailwindcss/vite` | UI, TDS-токены |
| `zustand` (+ persist middleware) | XP, прогресс, достижения, тема |
| `framer-motion` | анимации переходов модулей, карточек |
| `canvas-confetti` | конфетти |
| `@dnd-kit/core` | drag&drop игры (классификации) + click-fallback |
| `react-markdown` + `remark-gfm` | только для блока «как в конспекте» |

Квизы, флэш-карточки, симулятор, калькулятор — свои компоненты.
