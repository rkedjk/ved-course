# 📦 Учёт и анализ ВЭД — интерактивная лекция

Обучающая интерактивная лекция по предмету «Учёт и анализ ВЭД»: не сухие термины, а **живые примеры**, мини-игры, квизы, геймификация и приколы.

- **Лекция**: Карпунина Елена Валерьевна — к.э.н., доцент кафедры «Экономическая безопасность, анализ и учёт» РГРТУ им. В.Ф. Уткина
- **Разработка**: Радмир Мустафин — QA-инженер Т-Банка

Опубликовано на GitHub Pages: **<https://rkedjk.github.io/ved-course/>**

## Что внутри

### Тема 1. Сущность и гос. регулирование ВЭД

- **Что такое ВЭД и ВТД** — живая схема «экспорт или импорт» (товар едет через границу), ссылки на 183-ФЗ и 164-ФЗ
- **ТНК и кооперация** — как смартфон собирают из деталей из 5 стран: предметная / подетальная / технологическая
- **Классификация связей** — игра «Разложи по полочкам»: торговля, бартер, туризм, франчайзинг, инжиниринг
- **Субъекты ВЭД** — игра «Кто есть кто»: Президент, ФТС, Минфин и другие по корзинам компетенций
- **Таможенное регулирование** — кейсы «что это за мера»: эмбарго / квота / лицензия
- **Таможенные платежи и ставки** — калькулятор пошлины: адвалорная / специфическая / комбинированная

### Тема 2. Анализ валютных рисков

- **Валютная позиция** — живые «весы»: двигаешь активы и пассивы, весы показывают длинную/короткую/закрытую позицию
- **Кейс USD/JPY из лекции** — симулятор валютной позиции: продай 1 млн USD по 109,78, подними курс до 119,58 и увидь убыток 81 954 USD своими руками
- **Виды рисков** — кейсы: операционный / трансляционный / экономический

### Геймификация

- XP, уровни и прогресс (как в Duolingo), достижения-бейджи, конфетти за правильные ответы
- Квиз после каждого модуля, флэш-карточки для заучивания терминов, глоссарий с поиском
- Аннотации: кликабельные термины с тултипами, блоки «как в конспекте», ссылки на законы
- Мемы и easter egg 🥚
- 📳 Вибро-отдача на мобильных (Android) — настраивается в шапке
- 📱 Полностью адаптивно: нижняя навигация, safe-area, крупные тач-цели

## Запуск

```bash
npm install
npm run dev      # → http://localhost:5173
```

Сборка и проверка типов:

```bash
npm run build    # production-сборка в dist/
npm run check    # tsc -b
```

## Стек

React 19 + TypeScript + Vite + Tailwind CSS v4, стилистика Tinkoff Design System (жёлтый `#FFDD2D`, тёмная/светлая тема, Manrope). Библиотеки: `zustand` (прогресс/XP в localStorage), `motion` (анимации), `canvas-confetti`, `@dnd-kit` (drag&drop), `react-markdown`.

Деплой — GitHub Actions на GitHub Pages (`base: './'`).
