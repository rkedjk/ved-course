# Butter Squish v2 — переделка по фидбеку

## Context

Первая версия сквиша получилась слабой. Фидбек пользователя:

1. **«Не повернёшь»** — вращения брикета нет совсем: любой pointerdown только вминает.
2. **«Сквиш не сквишится»** — вмятина слабозаметная (глубина 0.22 при высоте 1, гранёная из-за малого числа сегментов), нет ощущения «сжимаю всей рукой».
3. **«Картинка не похожа на оригинал»** — самодельная этикетка, слишком бледный цвет, нет ощущения вощёной обёртки, нет «ушек»/складок, плоский свет без бликов.

Корни в текущем коде (`src/games/adhd/ButterSquish.tsx`):

- один обработчик pointerdown = только вмятина; rotate нет;
- `RoundedBoxGeometry(2.8,1,1, 4, 0.09)` — totalSegments=9: на большой грани мало вершин → вмятина угловатая;
- одна точка давления с `uDepth ≤ 0.22` — мягкого «плющащегося» брикета нет;
- свет: ambient + hemisphere + directional, без envMap → MeshPhysicalMaterial выглядит плоско;
- этикетка: тонкие полосы, мелкая надпись, без текстуры бумаги.

## Approach

### 1. Интерактив: мять ИЛИ вращать (жест по контексту)

- **Драг, начатый по маслу** → мять: raycast-точка едет за пальцем, шейдерная вмятина.
- **Драг, начатый по фону** (мимо масла) → **вращение брикета**: yaw += dx*0.01, pitch ±0.55 (ограничить), инерция затухает.
- Двойной тап по фону → сброс ракурса? (опционально, не обязательно)
- `touch-action: none` уже стоит.

### 2. Мощный сквиш (глобальный + локальный)

- **Глобальное сжатие**: пока зажато по маслу — вся группа брикета плющится: `scale.y → 0.72`, `scale.x/z → 1.08` (объём сохраняется), плавно нарастает; отпустил — пружинный slow-rise (~3с, k=8, c=2.8, перелёт).
- **Локальная вмятина**: та же инъекция шейдера, но глубина до **0.4**, радиус **0.55** (компактнее и глубже — заметнее).
- Сегменты: `RoundedBoxGeometry(2.8, 1, 1, 7, 0.1)` → totalSegments 15, гладкая вмятина.
- Вибро: `tick()` на тап; при отпускании — мягкий `tap()`-звук? (нет, оставлю squelch+tick на тапе).

### 3. Вид «как оригинал» (трендовая пачка)

- **Обёртка**: перед/зад — новая текстура: тёплый жёлто-кремовый фон с шумом бумаги, **крупная красная надпись BUTTER** (~130px, 900), овал-«печать» вокруг лого, красная полоса «SALTED BUTTER» сверху, тонкая синяя «150 г» снизу, рамка, вертикальные складки по краям, лёгкий noise.
- Верх/низ — «вощёная бумага»: кремовая текстура с горизонтальными складками (отдельная canvas).
- Торцы (+x/−x) — насыщенное сливочное масло (#f2c94c, roughness 0.15, глянец).
- **«Ушки» обёртки**: 2 маленьких скруглённых боксa сверху (тонкие выступы у переднего/заднего края) — имитация завёрнутой бумаги.
- **Свет**: `RoomEnvironment` + `PMREMGenerator` (three/addons, офлайн) → envMap; key directional 1.2; `clearcoat 0.5, clearcoatRoughness 0.3` на обёртке — живые блики «вощёности».
- Камера: fov 45, z 3.4; стартовый ракурс rotation.y=-0.45, x=0.18; canvas 200×200 (чуть крупнее).
- Idle-покачивание: оставить микро (амплитуда 0.02) — не мешает.
